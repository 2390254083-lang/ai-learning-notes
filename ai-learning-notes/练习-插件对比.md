# 练习记录：插件 Prompt 对比

测试文章：景德镇手工制瓷业遗址入选世界遗产名录

---

## 1. CoT 提示词 vs 原版

**CoT 版输出：**
- 景德镇手工制瓷工业遗产地入选联合国教科文组织世界遗产名录，成为中国首个完整的手工制瓷生产体系获得全球认可。
- 遗产由五个功能关联的组成部分构成：城区制瓷中心、湖田古窑遗址、高岭瓷土矿遗址、长岭瓷石矿遗址、焦坦柴火生产区，总面积 1979 公顷，缓冲区 5545.7 公顷。
- 遗产不仅包括古代窑址等有形遗存，还涵盖制瓷技术、工业组织和社会秩序等无形系统。

**原版输出：**
- 列入世界遗产（含详细说明）
- 遗产组成（5 个部分、面积数据）
- 各部分作用（逐项展开）
- 遗产价值

**结论：** CoT 版本更简短，突出重点；原版信息更全但偏啰嗦。

---

## 2. JSON 格式 + 示例 vs 原版

**JSON 版输出：**
- 逻辑清晰，五大组成部分各一行子项目
- 一眼看到重点

**结论：** 结构化输出最适合"总结"功能，格式模板 + 示例双重锁定。
