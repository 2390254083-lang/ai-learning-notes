# 05 — Prompt 三件套实战优化

> 基于 Week 1 所学的 Few-shot / CoT / 结构化输出，实际打磨浏览器插件 prompt

---

## 一、总结 prompt — 结构化输出 + 示例

**优化前：** 泛泛的"要点列表"，格式不固定

**优化后：** 固定三段式格式（一句概括 + 三个要点 + 保留数据）+ 示例锁定风格

**测试结果：** 旧版是一大段纯文本，新版结构分明，核心数字（5172.3亿）一眼可见。清晰度大幅提升。

---

## 二、翻译 prompt — One-shot

**优化前：** "流畅自然"是模糊愿望

**优化后：** 三条精确规则 + 环球时报风格示例

**测试结果：** 旧版拖沓（"——包括..."层层嵌套），新版拆成短句，专业简洁。

---

## 三、解释 prompt — 保持原版

**优化前：** 自然叙事 + 精准类比（AI 打电话叫工具）

**优化后：** CoT 分步框架，机械填表感，类比偏离（"妈妈做饭"不对应 Function Calling 的"叫别人干"）

**测试结果：旧版更好。** 用户评价："修改前解释得更好，我能看懂。"

**关键收获：不是所有任务都适合 CoT。** 解释类任务，一个精准的类比比十步思考流程管用。面试能讲出"什么时候不用"比"什么时候用"更高一档。

---

## 最终决策

| 功能 | 采用方案 | 原因 |
|------|---------|------|
| 总结 | 结构化输出 + 示例 | 格式固定，一眼抓重点 |
| 翻译 | One-shot | 示例锁定风格，简洁专业 |
| 解释 | **原版不变** | 好类比 > 强框架，CoT 反而破坏可读性 |

> 技巧是工具，不是公式。知道什么时候不用，才算真的学会了。
