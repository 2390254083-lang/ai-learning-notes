你的问题: 什么是Token？
[INFO] 检索 + 生成中...

回答:
Token 是 LLM（大语言模型）处理文本的最小单位。
英文约 1 个单词 = 1.3 个 Token，中文约 1 个字 = 2 个 Token。
Token 是计费单位，输入和输出都按 Token 数收费。

你的问题: RAG的完整流程是什么？
[INFO] 检索 + 生成中...

回答:
RAG（检索增强生成）的完整流程如下：

1. 文档加载 — 读入 PDF、TXT、网页等各种格式的文档
2. 文本分割 — 将长文档切成 500-1000 字的文本块，
块与块之间有重叠，避免信息断裂
3. 向量化存储 — 用 Embedding 模型将文本块转成向量
（语义指纹），存入向量数据库
4. 检索增强生成 — 用户提问时，先将问题向量化，
检索最相关的文档块，连同问题一起发给 LLM
